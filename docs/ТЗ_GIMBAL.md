# ТЗ — контроллер 3-осевого подвеса камеры GEC-BGC (плата 08 проекта 175)

Дата: 24.11.2026. Заказчик/владелец: Олег Гридин. Основание: решение Олега 24.11.2026 — собственный стабилизатор камеры на STM32 «по типу китайского подвеса», внешний модуль MPU-6050 на проводе, 3 мотора, своя прошивка, затем PCB.

## 1. Назначение и состав

Стабилизатор камеры (GoPro/экшн-камера или смартфон-класс, масса полезной нагрузки до ~300 г) на трёх бесколлекторных гимбал-моторах. Состав:

- плата контроллера GEC-BGC (эта разработка);
- выносной модуль IMU GY-521 (MPU-6050) на кадре камеры, кабель 4 провода;
- 3 гимбал-мотора (типовые GBM2804H-100T, 2208, 14 полюсов, сопротивление обмотки 5–15 Ом) — покупные;
- механика подвеса — `07 - CAD Design` (отдельная задача).

## 2. Требования

| № | Требование | Значение |
|---|---|---|
| G1 | Оси | 3 (pitch, roll, yaw), мотор yaw на MOT2 |
| G2 | Питание | 2S–4S Li-ion/LiPo, 6…17 В; защита от переполюсовки; потребление без моторов < 0.15 А |
| G3 | Ток мотора | до 1.5 А на мотор длительно, 2.5 А пик; ограничение напряжения на мотор программно (нагрев) |
| G4 | IMU | MPU-6050 на выносном модуле GY-521, I2C 400 кГц, кабель ≤ 30 см; второй порт I2C под IMU на раме / компас |
| G5 | Контур | частота петли ≥ 500 Гц, точность удержания ≤ 0.1° (pitch/roll) при вибрации коптера |
| G6 | Управление | RC PWM ×3 (+4 доп.), S.Bus (с аппаратным инвертором), Sum-PPM, UART (MAVLink у STorM32), потенциометры ×3, кнопка |
| G7 | Режимы | follow / lock по каждой оси, калибровка IMU, автоопределение числа полюсов и направления (STorM32 — есть; GEC-BGC — план) |
| G8 | Интерфейсы | USB (конфигурация, прошивка), SWD, UART 3.3 В (5 В-толерантный вход) |

| G13 | Ничего не заказывать | только разработка и проверки (правило проекта) |

## 3. Выбор архитектуры

### 3.1 Варианты, которые рассматривались

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **Клон STorM32 v1.3x на STM32F103RC** (выбран) | открытое железо (TAPR OHL), полная схема; бесплатная зрелая прошивка v2.74 (2025) работает сразу; есть открытые альтернативы (EvvGC, EvvGC-PLUS, порты SimpleFOC); F103RC в наличии | F103 72 МГц без FPU — для своей прошивки хватит синусного управления без энкодеров, настоящий FOC на 3 мотора тяжело (мнение runger, SimpleFOC) | **да** |
| EvvGC v1.x (STM32F103RC + L6234) | GPLv3-прошивка, MPU6050 | L6234 крупный, прошивки 2013–2015 заброшены, другая пин-карта | нет (как справочный код) |
| STorM32 v3.3/v4.1 (NT-модули, MPU9250 по SPI) | новее | драйверы вынесены на NT-модули, прошивка требует NT-IMU; сложнее и дороже | нет |
| STM32G431/F405 + SimpleFOC с энкодерами | FOC, тишина, точность | энкодеры в каждом моторе, другая механика; «клон китайского подвеса» теряет смысл | позже, v2 |

### 3.2 Драйверы моторов (остатки LCSC 24.11.2026)

| Драйвер | Наличие | Напряжение | Решение |
|---|---|---|---|
| DRV8313PWPR (у STorM32 v1.31) | C92482 — **0** на LCSC, только сторонние (2 625 шт., 3–5 дней) | 8–60 В | нет |
| L6234PD013TR | C77581 — 566 | 7–52 В | запасной (PowerSO-20, бутстреп) |
| **DRV8311HRRWR** | C5218862 — **7 891**, $1.75 | 3–20 В, 5 А пик, 3x PWM, датчик тока | **да**, ограничивает питание до 4S |
| DRV8316RRGFR | C5218861 — 1 385 | 4.5–40 В, 8 А | избыточен, SPI-вариант; для 6S-версии |

Факты DRV8311 (даташит SLVSFN2B, февр. 2022): VM 3…20 В (abs. max 24 В); 5 А пик; WQFN-24 3×3 мм, шаг 0.4 мм; режим 3x PWM выбирается MODE = AVDD/Hi-Z, при INLx = 1 выход = INHx (таблица 8-4); nSLEEP с внутренним пулдауном; nFAULT открытый сток; AVDD 3.3 В до 100 мА; RDS(on) 210 мОм (HS+LS); PWM до 200 кГц; логика 1.8/3.3/5 В.

### 3.3 MCU

STM32F103RCT6 (C8323, 256 шт. на LCSC + 16 740 у сторонних, $3.01; есть -TR C39704, 156 шт.). Выбран ради бинарной совместимости со STorM32. Своя прошивка — STM32duino 3.1.0, плата Generic F103RCTx, USB CDC.

### 3.4 IMU

MPU-6050 на LCSC только у сторонних поставщиков — на плату чип не ставим; используем модуль GY-521 (решение Олега: выносной модуль по проводу). MPU-6050 без магнитометра → yaw удерживается по гироскопу с дрейфом; компас — опция на IMU2 (GY-87 / MPU-9250 / QMC5883).

## 4. Прошивки

### 4.1 GEC-BGC (своя)

- Стек: STM32duino 3.1.0 + SimpleFOC 2.4.0 (3 × `BLDCDriver3PWM`, `angle_openloop`, синусная коммутация без датчиков положения) + MPU6050_light 1.2.1 (комплементарный фильтр).
- v0.1.0 (24.11.2026, собрана): инициализация 3 драйверов на пинах STorM32, IMU на I2C2 (PB10/PB11), 500 Гц петля, PID по углам, интегрирование скорости в угол открытого контура, команды по USB (`e1/e0`, `p/r/y<град>`, `c` калибровка, `s` статус), контроль nFAULT, измерение VBAT.
- План v0.2+: оценка ориентации Mahony с учётом углов моторов (IMU на камере → углы рамы), yaw по гироскопу с follow-режимом, RC/S.Bus входы, параметры в EEPROM (эмуляция во флэше), автокалибровка направления моторов, PWM 25–32 кГц, защита по току через SOA/SOB (если выделить АЦП), MAVLink gimbal protocol.
- Сборка — `firmware_GEC-BGC\BUILD_REPORT.md` (нужен патч SimpleFOC для ядра 3.x).

### 4.2 STorM32 o323BGC v2.74 (эталон)

Бесплатная, не открытая. Условия (LICENCE.txt): частное использование без ограничений; коммерческое — без модификации, бесплатно, с явным указанием автора и происхождения. Hex для платы v1.30 (`o323bgc_v274_nt_storm32bgc_v130_f103rc.hex`), GUI o323BGCTool v2.74 (Perl, exe). Заливка по USB/UART через GUI или SWD. С нашей платой: моторы — те же 9 PWM-пинов (3 на мотор), IMU камеры на разъёме «I2C» (PB10/PB11), второй IMU на I2C#2 (PB6/PB7); AUX0/AUX1 на нашей плате заняты nSLEEP/nFAULT (в STorM32 — входы кнопок, с подтяжкой к 3.3 В ничего не ломают).

### 4.3 Справочные открытые проекты (клоны в `C:\dev\gimbal_src`)

EvvGC/Firmware (GPLv3, F103RC, MPU6050, L6234), Nate711/EvvGC-PLUS (Apache-2.0, ChibiOS 2.6.7, MPU6050, таймеры TIM1/TIM5/TIM8 — другая пин-карта), dongfang/BGC32 (альтернатива для EvvGC), olliw42/storm32bgc (железо всех версий, бинарники).

## 5. Испытания

1. Плата без моторов: токи покоя, 5 В / 3.3 В, USB-энумерация, SWD.
2. GEC-BGC: `s` — чтение IMU; `e1` — моторы удерживают позицию без нагрева > 60 °C; `p10` — поворот оси на 10°.
3. STorM32 v2.74: прошить, GUI → Configure → автоопределение моторов, калибровка IMU, удержание горизонта.
4. На раме Q450 с работающими моторами коптера: дрейф yaw за 5 мин, колебания pitch/roll, нагрев драйверов, ток от 4S.
5. Сравнить две прошивки по качеству стабилизации (видео).
